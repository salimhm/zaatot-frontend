# Tech Stack

- **Runtime environment & Command Line**: Bun
- **Programming language**: TypeScript (strict)
- **Main framework**: React version 19.x.x
- **Routing framework**: @tanstack/react-router version 1.x.x
- **State Manager**: @tanstack/react-store version 0.x.x
- **Styling framework**: Tailwind CSS version 4.x.x
- **UI component library**: @mantine/core version 9.x.x + @mantine/hooks version 9.x.x + @mantine/form version 9.x.x
- **Icon usage**: `@phosphor-icons/react` version 2.x.x
- **API framework**: @tanstack/react-query version ^5.x.x
- **HTTP Client**: `@elysiajs/eden` (Eden Treaty) for type-safe API calls
