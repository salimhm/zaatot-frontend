# Aesthetics

- **UI Library**: Strictly use Mantine UI for ui building (with mantine hooks + everything from mantine...)
- **Theme style**: Light, with an Editorial Minimalism and Flat/Chromeless UI aesthetic (no glassmorphism)
- **Typography**: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
- **Primary color palette**: #00c951, #000000
- **Background color**: #fffcf2
- **Paddings**: medium, Gives content a "puffy," comfortable look.
- **Margins**: medium, Balanced spacing to keep the layout organized.
- **Borders**: No borders or quiet solid borders on interactive elements; chromeless borderless layouts for content containers.
- **Shadows**: None (flat design; no shadows or elevations).
- **Playful**: Small to medium border-radius (`sm` to `md`) on active components, bouncy hover effects, and cheerful color accents.
- **Responsive**: Mobile-first approach with responsive breakpoints.
- **NB**: Strictly use the colors i gave you!
