# Backend Connection

- The frontend connects to an ElysiaJS backend at `@api/index.ts` using Eden Treaty for full type safety. The backend's TypeScript types are automatically synced via `bun eden` which generates `src/eden.d.ts`. This enables autocomplete and compile-time error checking for all API calls. If the synchronization fails or the types are outdated, run the sync command again.

- **IMPORTANT**: All endpoint types, schemas, and API definitions are managed in `src/eden.d.ts`. Do not edit this file manually as it is overwritten during synchronization. Refer to this file or your IDE's autocomplete for API structures.
